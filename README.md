# Digitech Avenue CRM — Frontend

React + Vite SPA for Digitech Avenue CRM.

## Run

```bash
npm install
npm run dev
```

App: http://localhost:5173/

Point the API base URL at your Django backend (default in code: `http://127.0.0.1:8000/api`).

## Demo logins

| Role | Username | Password |
|------|----------|----------|
